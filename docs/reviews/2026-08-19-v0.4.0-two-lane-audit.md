## 6. 方法论留痕

- **红证优先**：每条修复前都把测试跑红（stash 源码 / 用 `git show HEAD:` 取旧文件），否则测试可能空转。
- **棘轮即预算**：ADR-006 的 `max(+2%, +10)` 逼着每一行注释自证价值；本轮为它删掉的注释比新增的代码还多。合法通道 `CE_ACCEPT_BASELINE=1` 会**抹平全部已存天花板**，代价远大于收益，未用。
- **改名会重编克隆成员 id**：`audit.rs → audit/mod.rs` 造成 `2 added / 2 removed`；改用 Rust 2018 的 `audit.rs + audit/changes.rs` 布局，路径不变、零扰动。
- **自家门咬手三次**（新测试互相克隆、模块索引撞型、文件破 300），三次都按门的意思改代码，一次没抬预算。
