## A 软区间（graded zone）——替换 warn/fail 双档悬崖

- 三段曲线：舒适区 `[0,S]` 零罚；渐进区 `(S,H]` 罚
  `p(x) = P_max × ((x−S)/(H−S))²`（凸——越近硬线罚越陡；整数/
  有理算术，判决在核）；硬线 `H` 语义不变（deny）。
- score 侧：size 轴由二值改梯度 = **分数迁移一次**，发版声明义务
  （[RELEASE.md](../RELEASE.md) §0，修正案①先例）。
- guard 侧 as-built：v0.6 落 observe 台账（`zone` 事件，S<行数≤H
  每写一记）；v0.7（计划 v2.7 ①）接线位置→档位映射（<25% observe
  / 25–75% warn / >75% ask / >H deny）——`ce.toml [guard]
  zone_tiers` 显式声明才启用，默认恒 observe，默认翻档仍以台账攒出
  的各档 FPR 记录为准（§6 同款）；武装后台账行加记映射档
  （feed 0.6.0）。

## B 相对阈值——基线锚定的分布围栏

- 软线随仓库自身分布浮动：`S = clamp(median + k×MAD(log-LOC),
  [200, 500])`，按**判决语言集**在**基线冻结时**的分布计算——
  防自指漂移：膨胀提交不能挪自己的球门柱；重锚只随
  `CE_ACCEPT_BASELINE` 具名重立。
- 硬线 `H = 750` 恒绝对：相对逻辑只能放宽舒适区，永不解除硬线。
- 先例：S1 命名轴已在核内做分布判定（归一化 Tsallis-2）；分位数是
  排序整数上的精确算术。

## C 拆分 ROI——「值不值得拆」给出数

- 对渐进区内文件计算 Split Advisory：
  - 缝候选 = 单元边界 × 文件内共引聚类 × 克隆块边界 × 单元
    co-change（churn 既有事实）。
  - 收益 B = 渐进区罚分回收 + dedup 预算效应 + 热/冷单元隔离。
  - 成本 C = 被切断的内引用数（=新增跨文件耦合面）+ 每新文件固定
    开销 φ（S0 扇出、心智负担）+ 基线重键噪声。
  - `ROI = B/C`（有理数）。
- 面：`ce structure --split-candidates`——top-N 文件 × 最优缝 ×
  ROI（例：「guard.rs: 缝在 L152（budget 规则簇），ROI 3.2——切
  2 条引用换回 41‰ 罚分」）。
- **区内仲裁**：过 S 而无可行缝（所有候选 ROI<1 = 高内聚长文件）
  → **自动豁免并落机器生成的 why**——「大项目文件天然长」的正面
  回答：长而内聚 = 豁免有据，长而可拆 = 给出刀口。
- 判决位置：缝/边/churn = Rust 测量事实；曲线/围栏/ROI 排名 =
  核内新 advisory 家族（或 structure/1 扩展）——**Haskell 占比
  第二叉的首个实弹**（v2.3 拍板的架构迁移承诺）。

## P4 实现实录（2026-08-20，as-built）

- **定价范围**（v1 两腿，v0.7 补齐四腿全额——wire 2.15.0）：
  benefit = 软区间罚回收（与 verdict 同一曲线权威
  `CE.Verdict.Soft`）；cost = 跨缝**提及边**×roiRefMilli(250) +
  **切穿克隆块**×roiCloneMilli(500) + 跨缝**共变对**×
  roiChurnMilli(150) + roiPhiMilli(500)，标定实录见下节。
- **共引代理**：真·文件内符号共引不存在于任何缓存（v0.6 映射实证）；

  计边——顾问面非强制面，可容。
- **面**：`ce structure --split-candidates`（CLI）；MCP 与 GUI 面
  v0.6 **蓄意不带**（工具面扩张各随其自己的决策批）。
- **自仓首跑实证**（S=294 口径复核 2026-08-20）：graph_ladder.rs
