判决家族

ce check

总门。七轴合成 0–1000 分，对基线银行只缩不涨的棘轮，外加 CI 硬地板。

ce dedup

winnowing 指纹的 T1/T2 克隆检测，克隆块预算只准往下棘。

ce clone

T3 近似克隆：Haskell 核的树编辑距离判决，改名换形的拷贝一并抓。

ce deadcode

缓存引用图上的存活性判决：无保留入边、无入口声明——判死，门就红。

ce docdup

文档与注释里的重复散文，活段上的精确 Jaccard 判决。

ce structure

树尺度结构熵：布局偏离、文档陈旧、冗余诸轴，整仓一览。

ce scan

逐文件逐函数的尺寸、复杂度、可读性——经典指标，核分级。

ce trend

主线历史上的分数轨迹——逐提交缓存、可重建、方向诚实。

守卫钩子

作为 Claude Code 插件：重复写入在落笔瞬间被拦，停止时审计，会话开始报健康。

信任锚

全部九个发布二进制——三平台 × ce / ce-core，v0.7.3 起再加三个 GUI 安装包——都以 SHA256 钉扎在 plugin/bin/manifest.env；tag 阶段逐 pin 校验、 等被打标提交的 CI 全绿、拒绝任何计划外资产，然后才发布。SHA256SUMS 覆盖 全集可离线核对。代码签名被刻意排除在设计外——哈希链就是永久信任锚。度量在 Rust， 判决在 Haskell，本仓库每次提交都用自己的工具给自己把门。
