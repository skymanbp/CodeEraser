CodeEraser™

LLM 写的代码会堆积——重复代码块、死文件、过期文档、结构蔓延。 CodeEraser 度量它、判决它、用一个只准变好的分数把住大门。

安装包 GitHub Releases — x86_64-windows · x86_64-linux · aarch64-macos，GUI + CLI + 判决核，SHA256 钉扎；Windows 安装包自动接入 Claude Code 插件（v1.0.1 起）
Cargo cargo install codeeraser
Claude Code /plugin marketplace add skymanbp/CodeEraser，再 /plugin install codeeraser@codeeraser
更新 ce update --yes

ce update 拿最新 tag 对比本构建（退出码 0 / 1 / 2）；--yes 在两枚 SHA256 pin 都通过后替换 ce 与 ce-core——但绝不动插件或 cargo 拥有的副本，它们各自给出自己的更新命令；--installer 则保存经校验的 GUI 安装包。GUI 有更新屏，Claude Code 里用 /codeeraser:update。

同一个七步任务，两份完全相同的种子树；唯一的变量是 CodeEraser 在不在环内——写入时的守卫、Stop 审计，以及审计拒绝之后按自己的计划执行的擦除。两次都仍以红色收场——但红的不是同一件事。

种子是 demo/seed/——一个精确到分的 Python + TypeScript 小型开票服务，两次运行之前先由同样的门量过、判为干净；任务是加折扣、紧凑报表、CSV 与 JSON 输出，以及 API 里的金额格式化。

判决家族

ce check

总门。七轴合成 0–1000 分，对基线银行只缩不涨的棘轮，外加 CI 硬地板。

ce dedup

winnowing 指纹的 T1/T2 克隆检测，克隆块预算只准往下棘。

ce clone

T3 近似克隆：Haskell 核的树编辑距离判决，改名换形的拷贝一并抓。

ce deadcode

缓存引用图上的存活性判决：无保留入边、无入口声明——判死，门就红。旁边是未被提及的声明顾问，它永不把门翻红。

ce docdup

文档与注释里的重复散文，活段上的精确 Jaccard 判决。

ce structure

树尺度结构熵：布局偏离、文档陈旧、冗余诸轴，整仓一览。

ce scan

逐文件逐函数的尺寸、复杂度、可读性——经典指标，核分级；判的是全局表，或该文件自己那条 [[rules.class]] 线。

ce trend

主线历史上的分数轨迹——逐提交缓存、可重建、方向诚实。

ce erase

确定性两段式擦除器：死文件、逐字重复的文档孪生、整单元精确克隆——先出计划，只在干净工作区上应用，且永不通过让模型重写代码来完成。

ce churn

git 窗口内的改动热度，逐单元归属——一个文件是在被重写，还是只在被追加。

ce join

三信号联判：把改动、重复与存活性折成一条判决，热的、重复的、已死的那个角落会自己报名。

守卫钩子

作为 Claude Code 插件：重复写入在落笔瞬间被拦，停止时审计，会话开始报健康。

信任锚

全部九个发布二进制——三平台 × ce / ce-core，v0.7.3 起再加三个 GUI 安装包——都以 SHA256 钉扎在 plugin/bin/manifest.env；tag 阶段逐 pin 校验、 等被打标提交的 CI 全绿、拒绝任何计划外资产，然后才发布。SHA256SUMS 覆盖 全集可离线核对。代码签名被刻意排除在设计外——哈希链就是永久信任锚。本仓库每次提交都用自己的工具给自己把门。
