靠什么守住诚实

项目给自己把门

每次 push，ci.yml 都在本仓运行七条产品腿。check 腿守住地板 911。

棘轮只缩不涨

ADR-006 把逐文件上限冻结在 ce-baseline.json。增长必须具名重立。

尺寸线可按路径类声明

[[rules.class]] 为一组 glob 声明自己的尺寸与复杂度线。各列见评分一节。

文档各有权威

CLI 与配置参考从二进制生成。引文、导航和常数测试检查方法学。

误报纪律

判定层：600 个样本命中 0 个（门 ≤ 1%）；写入探针：0/630 误报。其余规则保持 observe。每次晋级都须写入 CHANGELOG 台账。

擦除是确定性的

CE.Erase 只授权满足安全谓词的行。没有 LLM 负责重写。

发布分成两段

先为 draft 工件计哈希，再由提交的 pins 绑定这些字节。tag 作业全程不重建即发布。

方法可以逐行检查

十九册方法学把每条公式链接到实现它的 file:line。docs_citations.rs 查引文台账。

Haskell 真正承重

只有核能计算分数与棘轮判决、授权 erase 行。属性电池会扰动这些判决。

边界见 ADR-002 与 ADR-008； wire 见 contracts/VERSIONING.md；判决公式见 方法学索引。
