The tech stack

Measurement lives in Rust. Judgment lives in Haskell. One versioned wire connects them. This is the boundary set by ADR-002 and kept load-bearing by ADR-008: parsing, extraction and indexing stop before policy; score, ratchet and authorization stay in the core.

Where the mathematics lives

Rust · measurement
The rolling hash is Rabin-Karp, h = (h - t[i-k]*top)*BASE + t[i], over FNV-1a leaf hashes.
Wire
Raw counts cross the wire, never a ratio, or “the re-check lives in Haskell” would be an empty claim.
Haskell · judgment
There is no sampling temperature anywhere between the evidence and the verdict, no floating point in the judgment layer, and no model in the loop.
Faces
The same tree yields the same bytes on any machine at any hour, so a disagreement about code health is settled by re-running the number and reading the file:line it points at.
Release

What holds it honest

It gates itself

On every push, ci.yml runs seven product legs over this repository: scan, dedup ratchet, check at floor 911, deadcode, docdup, erase and rules.

The ratchet only shrinks

ADR-006 freezes per-file ceilings and discrete violation sets in ce-baseline.json.

More

Growth needs a named re-establish; ordinary cleanup tightens the bank.

Lines are declared, per path class

ce.toml's [[rules.class]] gives one glob set its own size and complexity lines and its own ratchet allowance, at most 64 classes, first declared match wins.

More

The score, the ce scan ladder and the guard hook read the file's own line. Class names and globs never cross the wire: what crosses is the class index, its knobs and the knobsDigest of the whole parsed config. The scoring section lists the columns.

Documentation has owners

docs_gate.rs generates CLI and configuration references from the binary.

More

Citation, navigation and constant tests check the methodology. Benchmark surfaces are byte-gated from one JSON contract.

False-positive discipline

classifier: 0/600 flagged (gate <= 1%); write probe: 0/630 false positives. Every other class stays observe. Each promotion is recorded in the CHANGELOG ledger.

Erase is deterministic

erase/gather.rs assembles facts; CE.Erase authorizes only rows that satisfy the safety predicate.

More

Apply verifies every target hash first, then re-runs the source families; a surviving verdict fails loudly. No LLM writes a replacement.

Release has two phases

release.yml hashes draft assets, then committed pins bind those bytes.

More

The tag job downloads the same assets, checks CI and every pin, and publishes without rebuilding. The same pins project the Homebrew formula and the winget manifests, and verify-publish fast-forwards the release branch the plugin marketplace tracks.

The method is inspectable

The nineteen-booklet methodology links every formula to its implementing file:line.

More

docs_citations.rs checks the ledger; docs_nav.rs checks the booklet set and navigation.

Haskell carries decisions

The core alone computes score and ratchet verdicts, authorizes erase rows, and decides cycle-axis membership.

More

Property batteries perturb those decisions and compare small cases with reference implementations.

Trace the boundary in ADR-002 and ADR-008, the wire in contracts/VERSIONING.md, and the verdict formulas in the methodology index.
